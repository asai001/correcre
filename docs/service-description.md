## 01 サービスの目的と概要

コレクレは、企業理念が社員に浸透しないとお悩みの「理想の組織」を創りたい経営者のために開発したシステムです。

### 目的：理念の浸透と企業文化の醸成

- 企業の理念に基づく具体的な行動を可視化し、評価・報奨することで、理念を基にした社内教育を行うことができます。
- ポイント交換という楽しみながら取り組める仕組みによって、社員がより積極的に参加し、行動を促すことができます。
- 従業員の積極的な参画を習慣化することで、経営者が目指す「理想の企業文化の醸成」を支援することを目的としたシステムです。

### サービス概要【全体像】：コレクレの理念浸透3STEP

| STEP | 名称 | 内容 |
|---|---|---|
| STEP1 | 具体化 | 企業の理念に沿って、社員にして欲しい具体的な行動と評価点数を【評価項目】として設定する |
| STEP2 | 行動化 | STEP1で設定した評価項目を社員が実行することで「評価点数」を獲得する |
| STEP3 | 習慣化 | 毎月ポイントが貯まる仕組みで、行動の繰り返しを促す。この習慣化によって、理念が浸透した企業文化を醸成していく |

**全体の流れ**

理念・ビジョン → 評価項目 → 評価点数を獲得 → ポイントを獲得 → アイテムへ交換 →（必要に応じて理念・ビジョンへフィードバック）

- 評価点数を獲得：会社が設定したレートで、獲得した評価点数をポイントへ変換する
- ポイントを獲得：溜まったポイントで好きな商品やサービスと交換が可能

## 02 社員に対する新しい評価基準

社員に対する報酬としては、業務に対する「給与」と、業績に対する「歩合」が一般的ですが、コレクレは新しい評価基準をご提案します。**理念・ビジョンへの貢献度に対して「ポイント」を付与する**新しい評価基準です。獲得した「ポイント」は、ポイント数に応じて各種アイテムに交換できます。

### 社員に対する評価基準

| 評価軸 | 対象 | 評価項目例 |
|---|---|---|
| 給与 | 業務に対して | スキル、勤続年数、資格、役職 |
| 歩合 | 業績に対して | ボーナス、インセンティブ |
| **ポイント（コレクレ）** | **貢献に対して** | 理念に沿った行動、個人的な頑張り、周りへの気遣い、向上心 |

### 評価項目例

1. 身の回りの掃除
2. 朝の活動
3. 自己学習
4. 地域への貢献
5. 改善提案

### ポイント交換アイテム例

## 03 評価項目＝ポイント獲得　進捗状況の管理

WEBシステム上で、従業員・管理者それぞれの画面から進捗状況を管理できます。

### 従業員ページ例

- ログイン後、企業の経営理念・Purposeを常時表示
  - 例）経営理念：「そうぞうの力で未来を描く／想像力と創造力で可能性を切り拓き続ける」
  - 例）Purpose：「中小企業の魅力を引き出し国力を上げる」
- ダッシュボードで自分の状況を確認
  - 今月の達成率／現在の保有ポイント／翌月反映予定ポイント／先月の獲得ポイント
- ミッション報告（項目ごとに進捗を報告）
  - 新しい意見／業務に関連する学習／チームワーク・共感力／誠実性／健康習慣　ほか
- その他機能
  - ポイント交換（商品・サービスと交換）
  - 過去の実績（月別スコア履歴）
  - 登録情報変更（プロフィール編集）

### 管理者ページ例

- 管理対象従業員数、先月総獲得ポイント、今月交換ポイント、企業保有ポイントを一覧表示
- 主な管理機能
  - **ユーザー管理**：ユーザー情報、権限、ログイン状況をまとめて確認し、登録や編集を行える
  - **分析・レポート**：全社傾向と個人分析を見ながら、日々の運用状況を確認できる
  - **各種情報画面**：理念体系、会社情報、ポイント設定、部署、ミッション定義、アカウント情報をまとめて確認・更新できる
- 報告内容一覧（日付／社員名／項目名／進捗／入力内容）を確認可能

> ※画面デザイン等は予告なく変更する場合があります。

## 04 コレクレ　導入の流れ

1. **理念等のヒヤリング**
2. **評価項目の策定**（打合せ3回前後）※STEP1の1週間後
3. **社員への説明会実施**※STEP2の2〜4週間後
4. **評価制度実施開始**
   - 実施開始後は、必要に応じて評価項目の見直しを行う

※理念等が無い場合は、ヒヤリングと並行して「理念等の策定」（1〜12ヵ月）を行ってから評価項目の策定に進みます。

**最短1ヵ月で導入可能**
※状況によって導入期間は変動します。
